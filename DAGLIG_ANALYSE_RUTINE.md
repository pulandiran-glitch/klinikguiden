# Daglig analyse-rutine

Brug 5 minutter på dette, når hjemmesiden er live.

## 1. Kig på trafik

I Google Sheet-dashboardet:

- Sidevisninger
- Guidevisninger
- Quiz-svar
- Beregnerbrug

Spørg dig selv: Hvad bruger folk faktisk?

## 2. Kig på leads

Tjek:

- `newsletter_signup`
- `pdf_download_started`
- `waitlist_signup`

Hvis mange downloader tjeklisten, men få køber, skal produktafdelingen på forsiden gøres stærkere.

## 3. Kig på betaling

Tjek:

- `checkout_started`
- `order_form_submit`
- Produkt
- Pris
- Estimeret omsætning

Hvis mange starter checkout, men få gennemfører, skal checkout-flowet testes og teksten før betaling gøres mere tryg.

## 4. Gem læring

Notér én ting:

- Hvad virkede?
- Hvad virkede ikke?
- Hvad skal ændres på siden?

Små forbedringer hver uge er bedre end store gæt.
